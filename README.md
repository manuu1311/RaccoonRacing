# RaccoonRacing
Recreation of the flash game "Raccoon Racing" in Godot.  
All original trademarks, characters, and copyrighted material related to the original Raccoon Racing belong to their respective owners.  

## Roadmap

| Status | Task |
|---|---|
| ⬜ | Game recreation |
| ⬜ | Online multiplayer support |
| ⬜ | RL integration |
| ⬜ | RL agent training |  

The goal is to train specialized RL agents with different objectives and behaviors, specifically:  
* Racing agents focused on winning  
* Aggressive agents focused on disrupting opponents
